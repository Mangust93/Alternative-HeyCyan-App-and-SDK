## Режимы направления («Кого переводим?»)

Один спиннер, 6 вариантов (объединяют языковую пару и направление):

| Индекс | Пункт | Распознавание | Перевод | Озвучка |
|--------|-------|---------------|---------|---------|
| 0 | Авто: русский ↔ английский (experimental) | ru-RU (bias) | по ML Kit Language ID внутри пары | по target |
| 1 | Я говорю по-русски → английский | ru-RU | ru → en | en |
| 2 | Собеседник говорит по-английски → русский | **en-US** | **en → ru** | **ru-RU** |
| 3 | Авто: русский ↔ испанский (experimental) | ru-RU (bias) | по ML Kit Language ID внутри пары | по target |
| 4 | Я говорю по-русски → испанский | ru-RU | ru → es | es |
| 5 | Собеседник говорит по-испански → русский | **es-ES** | **es → ru** | **ru-RU** |

Авто-режимы помечены экспериментальными: под спиннером показывается жёлтая подсказка, а в
статусе при старте и при неуспехе определения языка выводится:
«Авто-режим экспериментальный. Если английский плохо распознаётся, выберите режим
„Собеседник говорит по-английски → русский“». Авто-определение языка (ML Kit Language ID)
сохранено и используется только в авто-режимах.

Ключевой фикс EN→RU/ES→RU: в явных режимах язык распознавания берётся напрямую (`en-US` /
`es-ES`), а перевод не зависит от Language ID (которое часто мис-тегировало короткие
английские фразы при ru-RU распознавании). Это и есть причина прежнего «не переводит».

## Индикаторы состояния

Крупный лейбл «Состояние» вверху экрана показывает одно из:
`Готово`, `Слушаю…`, `Распознаю…`, `Перевожу…`, `Озвучиваю…`, `Скачиваю модели…`,
`Модели готовы`, `Ошибка`. Подробности/текст ошибки — в блоке «Подробности / ошибка» внизу.
Возврат в `Готово` после озвучки — через `UtteranceProgressListener.onDone`.

## Как тестировать

### EN→RU
1. Выбрать режим «Собеседник говорит по-английски → русский».
2. Нажать «Скачать модели» → дождаться `Модели готовы` / бейджа «готовы».
3. Нажать «Старт» (состояние `Слушаю…`, hint локали `en-US`).
4. Сказать английскую фразу.
5. Ожидаемо: «Исходная фраза» = английский текст; «Перевод» = русский; озвучка по-русски;
   состояние проходит `Распознаю… → Перевожу… → Озвучиваю… → Готово`.
6. Аналогично проверить ES→RU режимом «Собеседник говорит по-испански → русский».

### Скачивание моделей
1. Выбрать любую пару, нажать «Скачать модели».
2. Сразу должно появиться `Скачиваю модели…`.
3. При успехе — `Модели готовы` и бейдж «Модели текущей пары: готовы» (зелёный).
4. Выключить интернет и повторить — ожидаемо `Ошибка` + «Не удалось скачать модели.
   Проверьте интернет.»
5. Переключение пары сбрасывает бейдж в «не проверены» (зелёным станет снова после
   успешной загрузки/подтверждения наличия моделей этой пары).

### Ошибка распознавания (error 11)
1. Запустить распознавание, спровоцировать дисконнект сервиса (или дождаться кода 11).
2. Ожидаемо: `Ошибка` + «Сервис распознавания отключился. Нажмите Старт ещё раз.»
3. Приложение не падает; повторный «Старт» создаёт новый SpeechRecognizer (старый
   destroy-ится сразу при ошибке, новый — с cooldown 300 мс).

## Остаточные ограничения

- Авто-режимы по-прежнему зависят от качества системного распознавания и ML Kit Language ID;
  для надёжного EN/ES используйте явные режимы.
- Распознавание (SpeechRecognizer) использует системный движок и может требовать сети на
  части устройств; перевод/модели — офлайн после загрузки.
- TTS-голоса для ru/en/es зависят от установленных на устройстве движков; при отсутствии —
  сообщение «Язык озвучки недоступен».
- Модуль остаётся `exported=true` только для adb-запуска и debug-only; перед релизом —
  гейт флагом или реальная точка входа (см. AndroidManifest).
- Cooldown фиксированный (300 мс), без сложного scheduler — по требованию спринта.
